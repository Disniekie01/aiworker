FFW Pick & Place Launcher

Physics-grasp shirt pick/place in Isaac Sim — start services in order below.

Recommended workflow
  1. Start Isaac — launches UDP bridge + Isaac Sim (wait until the viewport shows the robot and scene).
  2. Tune poses — start the web tuner, adjust joints / crate / grasp, Write YAML, then turn Live publish OFF.
  3. Run YAML animation — plays the saved sequence (~40–50 s). Do not publish from the tuner at the same time.
  4. Repeat: tune → write YAML → disable live publish → run sequence.

YAML and tuner conflict: Both send commands to /ffw_isaac/joint_targets. Only one should publish at a time or the robot will jitter and skip steps. The tuner UI can stay open, but turn off Live publish before running YAML. Crate sliders also enable live publish — disable it first. Running YAML auto-disables tuner live publish if the tuner is up.

How to use Isaac
  • Starts run_stack.sh with pick-place + physics grasp (UDP bridge on port 15000).
  • First launch can take 1–3 minutes while Isaac loads Scene_clean.usda.
  • Confirm the FFW robot, crate, and shirt appear in the Isaac viewport before running YAML.
  • Check the log below if the window stays blank — look for errors after app ready.
  • Stop Isaac before changing USD paths or restarting the stack.

How to use YAML animation
  • Requires Isaac stack running (step 1).
  • Do not run while the tuner is live-publishing — both use /ffw_isaac/joint_targets.
  • Turn off Live publish in the tuner (or let this launcher disable it when you click Run).
  • Plays config/pick_place.yaml via ROS → UDP → Isaac (~40–50 s at 70% speed).
  • Sequence: Start → Ready → … → GRIPP (grip) → Lift → Turn → Drop (release) → Rest.
  • At GRIPP the shirt latches to the gripper; at Drop it releases.
  • Safe to run again after each pass completes.

How to use the web tuner
  • Requires Isaac stack running. Click Open tuner or go to http://127.0.0.1:8765.
  • Conflicts with YAML animation when Live publish is on — same ROS topic.
  • Tune poses, then Write YAML and turn Live publish OFF before running the sequence.
  • Crate and grasp sliders publish immediately and turn live mode on — disable live publish before YAML.
  • Select a step (e.g. GRIPP) and drag joint sliders — robot moves live in Isaac.
  • Grasp attach offset — tune while shirt is latched at GRIPP (ATTACH frame, not mesh inspector).
  • Only one tuner process per machine (port 8765). Cannot start while YAML is playing.
